# shadcn/ui Guidelines

## Overview

This project uses custom components along with **shadcn/ui** for reusable, accessible UI components, built with TypeScript, Tailwind CSS, and Radix UI primitives.

Official documentation: https://ui.shadcn.com/docs

## Component Guidelines

- Prefer existing components and shadcn/ui components over implementing UI primitives from scratch.
- Reuse components already installed in the project before adding new ones.
- Follow the project's existing design tokens, typography, spacing, and component variants.
- Use Tailwind CSS for styling.
- Preserve accessibility features, including keyboard navigation, focus management, and ARIA attributes.
- Avoid introducing additional UI libraries unless explicitly requested.

## Documentation References

- Components: https://ui.shadcn.com/docs/components
